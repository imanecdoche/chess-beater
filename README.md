# ChessBeater

**Interactive overlay mini‑board for Android chess apps**

## Overview
ChessBeater is an Android overlay application that provides a lightweight, semi‑transparent chess board that can be displayed on top of any other app.  The overlay:
- Renders a fully functional chess board that forwards touch events to the underlying application when appropriate.
- Supports an engine opponent, move validation, and automatic turn handling.
- Includes UI controls for quick calibration, engine toggling, and visual settings.

The project implements strict guardrails:
- `dispatchTouchEvent()` is never modified – it continues to pass‑through touches when the overlay is disabled.
- No calls to `resetGame()` are made from any settings dialogs.
- All piece‑ownership and legal‑move validation logic lives in `InteractiveBoardOverlayView.kt` and `ChessGameController.kt` only.

## Key Features
- **Auto‑Hide / Auto‑Show** – configurable timers to hide the overlay when inactive and show it on demand.
- **Piece‑ownership lock** – users can only move pieces that belong to them (no illegal opponent moves).
- **Strict move validation** – fully legal‑move checks using `ChessLogic.isMoveLegal`, including en‑passant, castling, and check detection.
- **Engine integration** – the overlay can run a built‑in engine that calculates moves while the UI remains responsive.
- **Calibration shortcut** – hold the board for two seconds to recalibrate quickly.
- **Settings UI** – extensive settings overlay with sections for appearance, automation, and anti‑cheat options.

## Getting Started
### Prerequisites
- Android Studio **2023.3+** with the Android SDK installed.
- Java 17 (or compatible) and Kotlin 1.9.
- Gradle wrapper (`./gradlew`).
- An Android device or emulator with USB debugging enabled.
- SSH key configured for GitHub (already set up for the user).

### Build & Install
```bash

# git clone git@github.com:imanecdoche/chess-beater.git

# Navigate to the project root
cd "/media/fatihfarhat/New Volume/PROJECTS/ChessBeater"

# Build the debug APK
./gradlew assembleDebug

# Install on a connected device
./gradlew installDebug
```

### Launch the Overlay
```bash
adb shell am start -n com.chessbeater.debug/com.chessbeater.MainActivity
```

The overlay will appear on top of the current foreground app.  Use the settings button (gear icon) to adjust visibility timers and other options.

## Development Details
### Core Files
| File | Purpose |
|------|---------|
| `InteractiveBoardOverlayView.kt` | Handles touch events, piece selection, move execution, and UI updates. Includes the **piece‑ownership guard** and **legal‑move validation**.
| `ChessGameController.kt` | Manages game state, turn handling, and engine calculations.
| `ChessLogic.kt` | Provides low‑level chess rules, move generation, and legality checks.
| `SettingsOverlayView.kt` / `SettingsActivity.kt` | UI for configuring overlay appearance, auto‑hide/show timers, and anti‑cheat settings.
| `MiniBoardOverlayService.kt` | Service that runs the overlay continuously in background.

### Guardrails Implemented
1. **No modification of `dispatchTouchEvent()`** – the method still forwards touches appropriately.
2. **No `resetGame()` calls from settings dialogs** – the game state is only reset via explicit user actions or engine events.
3. **Piece‑ownership lock** – added in `handleBoardTap()`; the overlay now checks `if (!chessGameController.isUserTurn) return false` and verifies the selected piece belongs to the player.
4. **Strict move validation** – `ChessLogic.isMoveLegal` is invoked before any board update; illegal moves are rejected without altering turn or board state.
